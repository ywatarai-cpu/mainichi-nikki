# まいにち日記

毎日気軽に書ける、本のような見た目の日記Webアプリです。
AI研修の課題として、Claude（Claude Code）と対話しながら作りました。

- 本体：`index.html` の1ファイル（約4,900行）。画面・見た目・動きがすべてこの中に入っています。
- 同じ `index.html` が、開く場所によって2通りに動きます。

| 開く場所 | 日記の保存先 | 共有・合言葉 |
|---|---|---|
| claude.ai の公開ページ（https://claude.ai/artifact/VxepZ6tPFqNAt6tjaZkvBJ ） | claude.ai の共有データベース | 使える |
| それ以外（Cloudflare Pages・手元で直接開く） | **そのブラウザの中**（IndexedDB） | 使わない（［共有］タブは出ません） |

### ファイル
| ファイル | 役目 |
|---|---|
| `index.html` | 日記アプリ本体 |
| `robots.txt` | 検索エンジンに載せないための指定 |
| `functions/_middleware.js` | Cloudflare Pages で動く Basic認証（ユーザー名とパスワードを聞く） |
| `.gitignore` | GitHub に上げないファイルの指定 |

> **用語メモ**
> - **Artifact（アーティファクト）**：claude.ai 上でWebページを公開・共有できる仕組み。
>   サーバーの用意は要りません。
> - **共有データベース**：Artifact に付いている保存場所。FileMaker でいう「ホストされたファイル」にあたります。
> - **IndexedDB**：ブラウザの中にある保存場所。FileMaker でいう「自分のPCに置いたローカルファイル」にあたります。
> - **Basic認証**：ページを開く前に、ブラウザがユーザー名とパスワードを聞くしくみ。

## 1. できること

| 画面 | できること |
|---|---|
| 一覧 | 日記を新しい順にカードで表示。言葉・月・タグ・気分・天気・写真/絵・付箋で検索／絞り込み、［× 条件をクリア］で全件に戻す。連続記録（○日連続）と「思い出」（1か月前・1年前の今日） |
| カレンダー | 書いた日に色と気分の顔。日付を押すと読む／書く。見出しを押すと年・月へひとっとび |
| 書く | 日付・気分・天気・タグ・タイトル・本文・写真・絵（手描き）。書くきっかけの問いかけ、書きかけの自動保存、保存時に「日記帳からのひとこと」 |
| 読む | 本のページのように1日分を表示。前の日／次の日へめくる、付箋を貼る |
| 記録 | 書いた日数・文字数・気分の割合・タグの割合・曜日ごとの気分などのグラフ（月ごと／すべて） |
| ふりかえり | 1年・1か月を文章でまとめる（いちばん書いた月、よく使ったタグ、気分の移り変わり、印象に残った日、写真・絵の思い出） |
| ゴミ箱 | 消した日記を30日間保管。1件ずつ／すべてを元に戻す・完全に消す |
| 設定 | 書き出し（CSV・Excel）、テーマ（ライト/ダーク×6色）、タグの編集、共有（リンクと送る文のコピー・合言葉）、表示の切り替え、データ（期間を選んでまとめて消す） |
| 使い方 | 画面ごとの説明 |

- 1日1件まで（同じ日付の日記は1つ）。
- スマホ・PCの両方に対応しています。
- 書けるのは持ち主だけです。共有された人は読むだけです。
- 共有された人には、最初に「合言葉」を聞きます。合言葉は**目隠し程度**の鍵です（2章）。

## 2. 使い方の流れ

### 持ち主
1. 公開ページを開き、右下の［＋ 今日の日記を書く］から書きます。
2. 右上のしおり［目次］から、各画面へ移ります。

### ほかの人に見せるとき
1. 目次 → 設定 → ［共有］で、合言葉を設定します。
2. claude.ai でこのページを開き、画面上部の［共有］から見せたい人を選びます。
3. ［共有］タブの［この文をコピー］で、リンク付きの案内文をコピーして送ります。
4. 合言葉は、案内文とは別の方法（口頭など）で伝えます。

相手は claude.ai にログインし、合言葉を入れると読めます。

> 合言葉は、元に戻せない形（ハッシュ）に変えて保存しています。
> ただし、詳しい人が調べれば日記の中身を見られる可能性があります。
> 本当の鍵は「共有で誰を選ぶか」です。

## 3. データのしくみ

FileMaker のテーブルにあたるものが3つあります。

### diaries（日記）— 1日1件。日付が「主キー」です

| 項目 | 内容 | 例 |
|---|---|---|
| date | 日付（`YYYY-MM-DD`） | 2026-10-25 |
| title | タイトル（空でもよい） | 【サンプル】みんなで夕飯 |
| body | 本文 | … |
| mood | 気分：great／good／normal／sad／angry（空＝未選択） | good |
| weather | 天気：sunny（晴れ）／cloudy（くもり）／rainy（雨）／snowy（雪）（空＝未選択） | cloudy |
| tags | タグ（複数） | ["家族", "健康"] |
| photoId / drawingId | 写真・絵のファイルの番号（ファイル本体は別の場所に保存） | — |
| note | 保存したときの「日記帳からのひとこと」 | — |
| milestone | 連続記録の節目（1週間・1か月…）のメッセージ | — |
| pinned | 付箋を貼ったか | true |
| createdAt / updatedAt | 作成日時・更新日時 | — |

### trash（ゴミ箱）
- 消した日記を、消した日時（deletedAt）付きで保存します。
- 名前は「日付_消した時刻」なので、同じ日付を何度消しても別々に残ります。
- 30日を過ぎたものは、持ち主が開いたときに自動で完全に消えます。

### settings（設定）
- `settings/lock`：合言葉のハッシュ
- `settings/tags`：タグの一覧

### 読み書きできる人（アクセス権）

| | 日記・設定 | ゴミ箱 |
|---|---|---|
| 持ち主 | 読む・書く | 読む・書く |
| 共有された人 | 読むだけ | 見えない |

### ブラウザに保存するとき（claude.ai の外）
- 上の3つを、ブラウザの IndexedDB（名前は `mainichi-nikki`）に同じ形で保存します。写真・絵も同じ場所に入ります。
- 日記は**そのブラウザの中だけ**にあります。スマホとPC、Safari と Chrome では別々の日記になります。
- 使う人はいつも「持ち主」として扱います。

### ブラウザだけに覚えるもの
テーマ・ダーク表示・一覧/カレンダーの別・表示の切り替え・書きかけの控えなどです。
その人のそのブラウザだけに残り、ほかの人には影響しません。
（`mainichi-nikki-` で始まる名前で、ブラウザの「localStorage」という保存場所に置いています）

## 4. 中身の作り（技術メモ）

- HTML・CSS・JavaScript を1つのファイルに書いています。ビルド（変換）作業はありません。
- 外から読み込んでいるもの：
  - 文字：Google Fonts（しっぽり明朝・クレー）
  - Excel 書き出し用の部品：SheetJS 0.18.5（cdnjs）。書き出すときだけ読み込みます
- claude.ai では Artifact の機能（`window.claude.use(...)`）を使います。
  claude.ai の外では、同じ使い方ができる代わりの部品（`localRuntime()`）を IndexedDB で用意して差し替えます。

| 機能名 | 使いみち |
|---|---|
| db | 日記・ゴミ箱・設定の保存 |
| user | 持ち主かどうかの判定 |
| assets | 写真・絵の保存 |
| downloads | CSV・Excel の保存 |

- Cloudflare Pages では、`functions/_middleware.js` が全ページの前に Basic認証をかけます。
  - ユーザー名とパスワードは、Cloudflare の環境変数 `BASIC_AUTH_USER`・`BASIC_AUTH_PASSWORD` から読みます（コードには書きません）。
  - 環境変数が無いときは、ページを出さずに止めます。
  - 検索エンジンに載せない指定を3か所に入れています（ページの robots メタタグ・`robots.txt`・サーバーの返事の `X-Robots-Tag`）。

- まとめて消す・戻す処理は、12件ずつ同時に進めます。混み合ったときは自動で件数を減らし、やり直します。
- コードの中のコメントは日本語です。
- `// =====` の見出しで、機能ごとに区切っています。

## 5. 直し方・反映のしかた

1. VS Code でこのフォルダを開き、Claude Code に「○○を直して」と日本語で頼みます。
   - `index.html` を直接編集してもかまいません。
2. 直したら、Claude Code に「公開して」と頼みます。
   - Artifact の公開機能で、**同じURLのまま**新しい版になります。
   - 公開ページを開き直すと反映されます。
3. 日記のデータは保存場所（データベース）にあるので、ページを直しても消えません。

> 別の会話から公開するときは、上の公開ページのURLを伝えてください。
> 伝えないと、別のURLの新しいページとして公開されます。

## 6. 注意点

- **サンプル日記**：2026年8月〜10月の日記は、タイトルに【サンプル】が付いた架空の内容です。
  - 不要になったら、設定 → ［データ］で期間を選んで消せます（ゴミ箱へ移ります）。
- **実在の情報を書かない**：日記・タグ・合言葉に、実在するお客様の名前・案件名・社内システムのパスワードなどを書かないでください。
- **合言葉**：ほかで使っているパスワードとは別の、この日記専用のことばにしてください。
- **ブラウザに保存するときの注意**
  - ブラウザの履歴・サイトデータを消すと、日記も消えます。
  - iPhone の Safari は、7日間ほどそのサイトを開かないと、保存したデータを消すことがあります。ホーム画面に追加して使うと消えにくくなります。
  - 大事な日記は、設定 → ［書き出し］で CSV・Excel にして控えを取ってください（写真・絵は書き出しに入りません）。
  - プライベートブラウズ（シークレットモード）では保存できません。

## 7. まだ確かめていないこと

開発中は、ブラウザを画面なしで動かす試験用ページで確かめてきました。次の点は本物の環境ではまだ確認していません。

- iPhone で入力欄を押したときに、画面が拡大されないか
- 読む画面のスワイプでページがめくれるか
- 幅の狭いスマホ（iPhone SE など）での見た目
- ［共有］タブの［コピー］が、ボタン1つでコピーできるか（できない場合は、手でコピーするよう案内が出ます）
- 共有された人が開いたときの、合言葉画面までの流れ
- 本番でまとめて消す・戻すのにかかる時間
- ふりかえり画面に本物の写真が並ぶか

## 8. 研修課題としての要件と対応

| 要件 | 対応 |
|---|---|
| 一覧・登録・編集・削除 | 一覧／書く画面（登録・編集共用）／ゴミ箱つきの削除 |
| スマホ対応 | 画面幅に合わせてレイアウトを切り替え（スマホ・PC） |
| ダミーデータのみ | サンプル日記はすべて架空。【サンプル】の印つき |
| 専門用語には注釈 | 画面の文言・このREADMEで用語に説明を付けています |
| URLで使える | claude.ai の Artifact として公開。Cloudflare Pages での公開（Basic認証つき）も準備中 |
